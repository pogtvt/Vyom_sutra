# Vyom Sutra: Universal Sine-Wave Hierarchy

A simulation and theoretical framework demonstrating how universal states (**Black Hole ⇌ Particle ⇌ Gravity ⇌ Dark Energy**) are unified manifestations of compressed and extended sine-wave mechanics.

## 🚀 Interactive Simulation
You can explore the interactive web simulation directly:
- **Live Demo:** [View Simulation](https://pogtvt.github.io/Vyom_sutra/) *(or check your GitHub Pages settings)*

## 📂 Project Structure
- `index.html` - Main HTML structure layout.
- `style.css` - Custom UI styling and dark theme design.
- `script.js` - Dynamic sine-wave canvas rendering and automated state-mapping logic.
